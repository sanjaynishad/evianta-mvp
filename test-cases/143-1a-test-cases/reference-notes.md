# Reference Notes and Scope

## Official references checked for this test pack

1. **Income Tax Department — “Prima Facie Adjustment Notice u/s 143(1)(a)” help page**  
   https://www.incometax.gov.in/iec/foportal/help/all-topics/e-filing-services/prima%20facie%20adjustment-UM?mobile-app=1  
   The page describes this as a preliminary proposed-adjustment communication, states a 30-day response period, and explains that the taxpayer can agree or disagree through e-Proceedings. The taxpayer should follow the deadline and workflow shown for the actual notice.

2. **Income Tax Department — example communication for proposed adjustment under Section 143(1)(a)**  
   https://www.incometax.gov.in/iec/foportal/e-Campaigns/e-mail/detail/9915  
   This illustrates the type of communication and points taxpayers to Pending Actions / e-Proceedings.

3. **Income-tax Act, 1961 — Section 143(1)(a)** (official Act text surfaced by Income Tax Department search)  
   https://www.incometaxindia.gov.in/w/section-143-27  
   The provision concerns specified processing-stage adjustments, including arithmetic errors; certain incorrect claims apparent from return information; certain prior-year loss set-off issues; specified tax-audit-report disallowances; and income reflected in Form 26AS, Form 16A or Form 16 but not included in returned income. Check the applicable law, Rules, notifications and tax year before using any of these categories in an actual matter.

## Design principle

A response is not the same as a final assessment or legal opinion. A good agent should cite the exact source documents it relied on, expose contradictions, state which facts are absent, avoid calculating a final tax demand unless the needed information is present, and route consequential decisions to a Chartered Accountant / qualified tax professional.

## Historical-law caution

This dataset specifically tests the legacy label “Section 143(1)(a)” for AY 2025–26. Tax-law terminology and portal references can differ by tax year after statutory changes. Never mechanically reuse this notice label or deadline logic for a real current-year matter without checking the actual communication and applicable law.
